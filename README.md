# আমার সহকারী

## GitHub Pages-এ চালু করা
1. সব ফাইল একটি রিপোজিটরিতে আপলোড করুন (ফোল্ডারের ভেতরের ফাইলগুলো, ফোল্ডার নয়)।
2. Settings, Pages, Branch: main, Save।
3. ফোনের Chrome-এ লিংক খুলে "Install app" বা "Add to Home screen" চাপুন।

## নিরাপত্তা
- API key কোথাও কোডে লেখা নেই। এটি শুধু আপনার ফোনের ব্রাউজারে থাকে। কখনো key কোডে বা রিপোজিটরিতে বসাবেন না।
- শুধু এই অ্যাপের জন্য আলাদা key বানান এবং Anthropic Console-এ খরচের সীমা দিন। কখনো সন্দেহ হলে key বাতিল করে নতুন নিন।
- AI চালু থাকলে প্রশ্ন ও প্রাসঙ্গিক নোট Anthropic-এর কাছে যায়। "ব্যক্তিগত" চিহ্ন দেওয়া নোট কখনো যায় না।
- অ্যাপ কোনো লগ রাখে না, কোনো অ্যানালিটিক্স বা তৃতীয় পক্ষের স্ক্রিপ্ট নেই। কেবল api.anthropic.com ও generativelanguage.googleapis.com-এর সঙ্গে সংযোগ অনুমোদিত (CSP)।
- Gemini ফ্রি টিয়ারে Google প্রশ্ন ও নোট নিজেদের উন্নয়নে ব্যবহার করতে পারে। সংবেদনশীল তথ্য পাঠাবেন না।
- রিপোজিটরি শুধু HTTPS-এ (GitHub Pages) চালান। রিপোজিটরি পাবলিক হলে তাতে ব্যক্তিগত নোট বা ব্যাকআপ রাখবেন না।
