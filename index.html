খাতা

সহকারী নিজে যা শিখতে চায়, তা এখানে জমা হয়। আপনি অনুমোদন না দিলে কিছুই স্থায়ী হয় না।

নোট শুধু এই ফোনে থাকে। ব্যাকআপে API key যায় না। ব্যাকআপে ব্যক্তিগত তথ্য থাকতে পারে, তাই নিরাপদ জায়গায় রাখুন।

ফ্রি key: aistudio.google.com এ গিয়ে Get API key চাপুন। ফ্রি টিয়ারে Google আপনার প্রশ্ন ও নোট নিজেদের উন্নয়নে ব্যবহার করতে পারে, তাই সংবেদনশীল কিছু পাঠাবেন না।

AI চালু থাকলে আপনার প্রশ্ন ও প্রাসঙ্গিক নোট নির্বাচিত সেবার (Google বা Anthropic) সার্ভারে যায়। শুধু এই অ্যাপের জন্য আলাদা key বানান, আর পেইড key-তে খরচের সীমা দিন।
